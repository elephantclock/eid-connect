For your developers

A few lines of code.

The service streams each card read to your app over local HTTP. Any language works; this is JavaScript.

import { connect } from '@elephantclock/eid-connect';

connect({
  onCard: (card) => {
    form.name.value   = card.nameEnglish;
    form.nameAr.value = card.nameArabic;
    form.eid.value    = card.idNumber;
    photo.src         = card.photoDataUrl;
  },
});

Questions

Frequently asked questions

Does EID Connect verify the card with the government?

EID Connect reads the data stored on the card chip, for capture, auto-fill and onboarding. Online validation against government records, needed for regulated eKYC, is a separate service. Ask us about it.

Which card readers are supported?

Standard PC/SC smart-card and NFC readers that work with Emirates ID. We recommend models and can help you buy them.

Does it work with our existing system?

Yes. Any web application can receive card data, and we integrate with CRMs, hospital, hotel and property-management systems, and ERPs.

Do we need to install anything in the browser?

No. A small Windows service runs on the counter PC, and your web app connects to it directly.

Is Emirates ID data stored?

The service itself stores nothing. Your application decides what to keep, and we help you keep the minimum needed under UAE data-protection law.
